## Задания

1. Чек-лист, 5 тест-кейсов и 3 баг-репорта (BR-001, BR-002, BR-003). Дефекты нашёл на портале и исправил, после этого проверил ещё раз.
2. Анализ запроса `POST /api/login` и страницы `/dashboard` в DevTools: метод, статус, заголовки, тело запроса и ответа, cookie.
3. Тестирование форм регистрации и входа: 34 проверки (валидация полей, позитивные и негативные сценарии), результаты в `Скриншоты/Задание 3 формы/результаты_проверки_форм.json`.
4. Автотест формы входа на Selenium со скриншотом при падении.
5. Смоук-тесты и запуск в GitHub Actions.

## Как запустить автотесты

Тесты запускают сам портал, поэтому работают из его репозитория. Здесь лежит копия кода для отчёта.

```
git clone https://github.com/Cla1ve/conference-portal.git
cd conference-portal
pip install -r autotests/requirements.txt
python -m pytest autotests -c autotests/pytest.ini --rootdir .
```

Нужен Chrome. Тесты работают с временной базой, рабочую не трогают.
